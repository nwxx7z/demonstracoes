# Quintino — Restaurante e Lanchonete

Demonstração front-end estática, responsiva e independente de framework.

## Abrir
Publique o repositório no GitHub Pages (branch main, pasta raiz) e visite:

`/quintino/`

No GitHub Pages deste repositório: `https://nwxx7z.github.io/demonstracoes/quintino/`

Para pré-visualização local, abra `index.html` no navegador, sem servidor de API.

## Arquivos
- `index.html`: homepage, cardápio, carrinho e toolbar.
- `style.css`: design, animações, breakpoints 320/360/390/430/768/1280 px.
- `app.js`: catálogo, busca, filtros, configurador de marmita P/G, acompanhamentos, sacola, frete ilustrativo e mensagem do WhatsApp.
- `assets/foods.webp`: atlas de 16 imagens culinárias ilustrativas.
- `assets/hero.webp`: imagem de destaque.

## Personalização
Em `app.js`, modifique as constantes `WHATSAPP`, `products`, `proteins`, `sides`, `prices`, `fees` e `deliveryNames`. O catálogo foi inspirado no cardápio fornecido. Fotos, operação, área de entrega e fluxo de pedido são demonstrativos.

**WhatsApp de demonstração:** +55 82 99318-8030 (desenvolvedor), não o WhatsApp do restaurante. A mensagem é pré-preenchida para revisão e não é enviada automaticamente.

A toolbar mobile é inspirada no vídeo de referência e mantém o modo de movimento reduzido (`prefers-reduced-motion`).
