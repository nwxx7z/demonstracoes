# Fogazza da Nice — demo de cardápio

Front-end independente em HTML, CSS e JavaScript puros, com rota `/fogazzadanilce/` no GitHub Pages.

URL prevista: https://nwxx7z.github.io/demonstracoes/fogazzadanilce/

## Arquivos
- `index.html` — homepage, hero, cardápio, seção de informações, homebar mobile e sacola.
- `style.css` — identidade terracota/creme/sálvia, glassmorphism leve, kinetic type, breakpoints e `prefers-reduced-motion`.
- `app.js` — catálogo, categorias, pesquisa, indisponibilidade, carrinho, validação do pedido e mensagem demonstrativa.
- `assets/fogazza.svg` — ilustração autoral, leve e local.

## Catálogo (parcial)
Há **32 produtos/variações** transcritos de **nove capturas de tela fornecidas pelo usuário**. Alguns registros apresentam nomes ou ingredientes cortados: esses são marcados como "Detalhes a confirmar". Itens sinalizados como indisponíveis nas capturas não podem ser incluídos no carrinho.

**Atenção:** os dados refletem somente o que estava visível nas capturas; **não representam uma verificação em tempo real** da disponibilidade ou dos preços. Há produtos não contemplados nas imagens. Consulte diretamente o estabelecimento para confirmar o catálogo.
