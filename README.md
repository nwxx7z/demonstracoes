# Demonstrações — Gunter Bauer Developer

Demonstrações front-end independentes, compatíveis com GitHub Pages, sem build e sem dependência de backend.

## Endereços

- `/sushimizu/` — Mania Sushi, cardápio demonstrativo.
- `/quintino/` — Quintino, restaurante e lanchonete; homepage, 16 itens, configurador P/G e toolbar mobile.
- `/fogazzadanilce/` — Fogazza da Nice, homepage animada, catálogo parcial dos prints, filtros, sacola e homebar mobile.
- `/biglanche/` — Big Lanche (demo isolada), 112 itens do catálogo, hero gamer, carrinho e cozinha de testes em `/biglanche/kitchen/`.
- Outras demonstrações podem ser criadas como `/nomedademo/`, cada uma contendo seu próprio `index.html`.

## Publicação no GitHub Pages

Em **Settings → Pages → Build and deployment**, selecione **Deploy from a branch**, branch **main**, diretório **/(root)** e **Save**. A URL do projeto será `https://nwxx7z.github.io/demonstracoes/`. O cardápio abrirá em `https://nwxx7z.github.io/demonstracoes/sushimizu/`.

O modelo utiliza HTML, CSS e JavaScript puros. O catálogo e as taxas de entrega são demonstrativos (não representam tabela comercial real).
